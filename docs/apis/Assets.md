This script allows for preloading assets.

Preloading the assets can, but doesn't have to happen inside of an app.

## Preload

First argument is a string - assetid of the asset you want to preload.

Second argument is a boolean - if this call should be async.

Third argument is a callback function - the function to execute when the assets finish loading.

## Preloadbulk

First argument is a table of strings - assetids of the assets you want to preload.

Second argument is a boolean - if this call should be async.

Third argument is a callback function - the function to execute when the assets finish loading.
