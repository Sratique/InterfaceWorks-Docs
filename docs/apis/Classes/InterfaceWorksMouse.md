This class handles mouse input for the stroke. It allows for cross-environment (Plugins and the Roblox Client) unification of the scattered Roblox mouse apis.

> Inherits from:
>- [InterfaceWorksBase](/docs/apis/Classes/InterfaceWorksBase.md)

## API

- `:GetLocation()` - Returns the current position of the mouse.

## Properties

- Root
    - Used for connecting all the apis together.
